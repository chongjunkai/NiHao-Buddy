Dictionary 好词好句 Import

Paste licensed dictionary notes or your own curated source. The app only accepts rows where the phrase and sentence contain the target character.

char,grade,meaning,phrase,sentence,source
克,6,第1课 识读字,克服困难,他终于克服困难，完成了这项挑战。,my notes

CSV Format

Use a header row. Supported columns include char, word, hanzi, 汉字, pinyin, meaning, and grade.

char,pinyin,meaning,grade
坚持,jiān chí,persevere,custom
责任,zé rèn,responsibility,custom

The app saves imports to data/custom_imports.csv, then rebuilds them into SQLite whenever NiHao Buddy restarts.
